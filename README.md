# Gemini AI Desktop Assistant 🤖

A responsive desktop AI chatbot built using **Python** and the **Eel library**, powered by **Google Gemini AI models**. This project combines a clean UI with intelligent backend processing to deliver a smooth conversational experience.

---

## 🚀 Features

* 🧠 **Gemini AI Integration** – Uses Google’s latest Gemini models for intelligent responses
* 🔤 **NLP Processing** – Tokenization using NLTK for better query understanding
* 💾 **Persistent Chat Memory** – Stores conversations in a local JSON database
* 🔄 **Dynamic Model Fallback** – Handles high server load by switching between models
* 🎨 **Modern UI** – Pastel glassmorphism design with animations
* 📝 **Markdown Support** – Clean, formatted chatbot responses
* ⚡ **Fast & Lightweight** – Built with Eel for seamless Python + Web integration

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python
* **Libraries:** Eel, NLTK
* **AI Model:** Google Gemini API
* **Database:** JSON (Local Storage)

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/your-username/gemini-ai-desktop-assistant.git
cd gemini-ai-desktop-assistant
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Add your Gemini API key in the config file:

```
API_KEY = "your_api_key_here"
```

4. Run the application:

```
python main.py
```
